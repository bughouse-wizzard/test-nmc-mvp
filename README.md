# НМЦК Поиск - Интеграция статического фронтенда

## Описание
Интеграция статического фронтенда с FastAPI бэкендом для поиска нормативных максимальных цен контрактов (НМЦК) в ЕИС Госзакупки.

## Структура проекта

```
.
├── app/
│   └── static/
│       ├── index.html          # Главная HTML страница фронтенда
│       ├── css/
│       │   └── styles.css      # Стили CSS
│       └── js/
│           └── app.js          # JavaScript логика
├── main.py                     # FastAPI приложение
├── requirements.txt            # Зависимости Python
└── README.md                   # Документация
```

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 3. Доступ к приложению
- Фронтенд: http://localhost:8000/static/index.html
- API документация: http://localhost:8000/docs
- Альтернативная документация: http://localhost:8000/redoc

## API Эндпоинты

### GET /
Корневой эндпоинт с информацией о сервисе.

### GET /api/health
Проверка состояния сервиса. Возвращает статус "healthy".

### GET /api/info
Информация о доступных эндпоинтах API.

### GET /static/{path:path}
Доступ к статическим файлам фронтенда.

## Фронтенд

Фронтенд представляет собой веб-интерфейс для поиска НМЦК с функциями:
- Поиск по истории запросов
- Фильтрация и пагинация результатов
- Визуализация прогресса поиска
- Уведомления и модальные окна

## Архитектура

1. **FastAPI** - бэкенд фреймворк
2. **StaticFiles** - обслуживание статических файлов
3. **Разделение кода** - HTML, CSS и JavaScript в отдельных файлах
4. **REST API** - эндпоинты для проверки состояния и информации

## Тестирование

Для проверки работоспособности:

