# НМЦК Поиск - Интегрированное приложение

Это приложение интегрирует статический фронтенд в FastAPI бэкенд для поиска и анализа контрактов для расчета НМЦК.

## Структура проекта

```
├── app/static/              # Статические файлы фронтенда
│   ├── index.html          # Главная HTML страница
│   ├── css/styles.css      # Стили CSS
│   └── js/app.js           # JavaScript логика
├── main.py                 # FastAPI приложение
├── requirements.txt        # Зависимости Python
└── README.md              # Документация
```

## Функциональность

### Фронтенд
- Поиск контрактов по названию и КТРУ
- Загрузка файлов ТЗ для автоматического заполнения
- История поисков с пагинацией
- Таблица результатов с фильтрацией
- Визуализация прогресса поиска
- Выбор контрактов для расчета НМЦК

### Бэкенд (FastAPI)
- Обслуживание статических файлов через `/static/`
- Health check endpoint: `GET /api/health`
- Mock endpoints для поиска:
  - `POST /api/search` - запуск поиска
  - `GET /api/search/{search_id}` - статус поиска
  - `GET /api/search/{search_id}/results` - результаты поиска

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
python main.py
```

3. Откройте в браузере:
```
http://localhost:8000/static/index.html
```

## API Endpoints

- `GET /` - информация о приложении
- `GET /api/health` - проверка работоспособности API
- `POST /api/search` - запуск нового поиска
- `GET /api/search/{search_id}` - получение статуса поиска
- `GET /api/search/{search_id}/results` - получение результатов поиска

## Архитектура

Приложение использует:
- **FastAPI** для бэкенда с автоматической документацией OpenAPI
- **StaticFiles** для обслуживания статических файлов
- **CORS middleware** для кросс-доменных запросов
- **Modern JavaScript** с использованием Fetch API
- **Tailwind CSS** для стилизации
