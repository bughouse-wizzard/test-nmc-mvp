# НМЦК Поиск Система

Автоматизированная система определения начальной максимальной цены контракта (НМЦК) на основе анализа контрактов из ЕИС Госзакупки.

## Структура проекта

```
.
├── app/
│   └── static/
│       ├── index.html          # Главная HTML страница (бывший front13.html)
│       ├── css/
│       │   └── styles.css      # Стили CSS
│       └── js/
│           └── app.js          # JavaScript логика
├── main.py                     # FastAPI приложение
├── requirements.txt            # Зависимости Python
└── README.md                   # Документация
```

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск сервера

```bash
python main.py
```

Или с использованием uvicorn напрямую:

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 3. Доступ к приложению

После запуска сервера откройте в браузере:

- **Главная страница**: http://localhost:8000/
- **API Health Check**: http://localhost:8000/api/health
- **API Info**: http://localhost:8000/api/info

## API Endpoints

### GET `/`
Возвращает главную HTML страницу приложения.

### GET `/api/health`
Проверка работоспособности API. Возвращает статус системы.

**Пример ответа:**
```json
{
  "status": "healthy",
  "service": "НМЦК Поиск Система",
  "version": "1.0.0",
  "timestamp": "2024-01-01T00:00:00Z"
}
```

### GET `/api/info`
Возвращает информацию о системе.

**Пример ответа:**
```json
{
  "name": "Система поиска НМЦК",
  "description": "Автоматизированная система определения начальной максимальной цены контракта",
  "features": [
    "Поиск контрактов по КТРУ",
    "Парсинг документов закупок",
    "AI-скоринг соответствия",
    "Расчёт НМЦК"
  ]
}
```

## Статические файлы

Все статические файлы (HTML, CSS, JavaScript) доступны по пути `/static/`:

- CSS: `/static/css/styles.css`
- JavaScript: `/static/js/app.js`
- Изображения и другие ресурсы: `/static/`

## Функциональность фронтенда

Фронтенд приложение включает:

1. **Панель поиска** - ввод параметров для поиска контрактов
2. **История поисков** - просмотр предыдущих поисковых запросов
3. **Таблица результатов** - отображение найденных контрактов
4. **Модальные окна** - детальное сравнение контрактов
5. **Расчёт НМЦК** - автоматический расчёт начальной максимальной цены контракта

## Технологии

- **Backend**: FastAPI (Python)
- **Frontend**: HTML, CSS, JavaScript
- **Стилизация**: Tailwind CSS, Font Awesome
- **Сервер**: Uvicorn (ASGI сервер)

## Разработка

Для разработки рекомендуется использовать виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate     # Windows
pip install -r requirements.txt
```
