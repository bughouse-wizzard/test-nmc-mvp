# НМЦК Поиск Система

Система для автоматизированного поиска контрактов и расчёта начальной максимальной цены контракта (НМЦК).

## Структура проекта

```
.
├── app/
│   └── static/
│       ├── index.html          # Главная HTML страница
│       ├── css/
│       │   └── styles.css      # Стили
│       └── js/
│           └── app.js          # JavaScript логика
├── main.py                     # FastAPI приложение
├── requirements.txt            # Зависимости Python
├── test_app.py                 # Тесты структуры
└── README.md                   # Документация
```

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
python main.py
```

3. Откройте в браузере:
- http://localhost:8000/ - интерфейс системы
- http://localhost:8000/api/health - проверка состояния API

## API Endpoints

- `GET /` - Главная страница интерфейса
- `GET /api/health` - Проверка состояния системы
- `GET /api/info` - Информация о системе
- `GET /static/{path}` - Статические файлы (CSS, JS)

## Функциональность интерфейса

Интерфейс включает:
- Поиск контрактов по КТРУ и параметрам
- История поисков с пагинацией
- Таблица результатов с фильтрацией
- Выбор контрактов для расчёта НМЦК
- Модальные окна для сравнения характеристик
- Уведомления о действиях

## Технологии

- **Backend**: FastAPI (Python)
- **Frontend**: HTML, CSS, JavaScript
- **Стили**: Tailwind CSS, Font Awesome
- **Сервер**: Uvicorn (ASGI сервер)
